# IFHE Workflow Investigation and Curriculum Audit

## Project Overview

This repository contains two connected student investigations:

- **Task 1 — College Workflow Investigation:** Investigating and redesigning a campus maintenance issue reporting and assignment workflow using an existing website prototype.
- **Task 2 — Curriculum Audit and Redesign:** Reviewing the B.Tech Computer Science and Engineering curriculum and proposing evidence-based improvements aligned with relevant job requirements.

## Task 1: College Workflow Investigation

The investigation examines report submission, administrative review, maintenance assignment, workflow failures, permissions, and recovery procedures.

Folder: [`task-1-workflow/`](task-1-workflow)

## Task 2: Curriculum Audit and Redesign

The curriculum audit will map semester-wise courses and credits, evaluate proposed KEEP, UPDATE, REDUCE, and ADD changes, compare real job descriptions, document AI-assisted exercises, and include an interactive credit calculator.

Folder: [`task-2-curriculum/`](task-2-curriculum/)

## Supporting Evidence

Folder: [`evidence/`](evidence/)

This folder will contain the source register, permitted supporting evidence, personal contribution statement, and limitations.

## Evidence and Integrity

Observed facts, estimates, assumptions, proposed changes, and synthetic test results will be distinguished clearly. No private student information, credentials, or confidential college records will be committed.
